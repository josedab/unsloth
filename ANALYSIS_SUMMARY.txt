================================================================================
RECOMMENDATIONS FOR USERS
================================================================================

For PRODUCTION:
  1. Identify GPU: nvidia-smi
  2. Get CUDA version: nvidia-smi | grep CUDA
  3. Select matching profile: pip install unsloth[cu121-torch250]
  4. Test before full deployment
  5. Pin all versions in requirements.txt

For DEVELOPMENT:
  1. Use editable install: pip install -e ".[huggingface]"
  2. Consider development dependencies for testing
  3. Use virtual environment to isolate dependencies
  4. Monitor library updates for breaking changes

For AMPERE GPUS (A100, RTX 30/40):
  1. Use ampere profile: unsloth[cu121-ampere]
  2. Includes flash-attn for 2-3x speedup
  3. Verify flash-attn installed correctly
  4. Profile performance before/after

For NON-NVIDIA:
  1. Intel GPU: unsloth[intel-gpu-torch280]
  2. AMD GPU: unsloth[amd]
  3. These are experimental - expect limited support
  4. CPU-only: Core unsloth available but slow
